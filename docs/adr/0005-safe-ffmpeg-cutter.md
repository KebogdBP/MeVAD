# ADR 0005: Safe FFmpeg Video Cutter

**Статус:** accepted
**Дата:** 2026-07-25

## Контекст

Обрезка должна поддерживать быстрый результат без потери качества и точные
границы, при этом пользовательский ввод не должен попадать в shell.

## Решение

- Представлять диапазон типизированным `ClipInterval`.
- Проверять длительность через FFprobe до запуска FFmpeg.
- Поддержать `fast` stream-copy и `accurate` H.264/AAC modes.
- Передавать процессу только массив доверенных аргументов с `shell=False`.
- Использовать bounded timeout.
- Писать во временный файл и атомарно публиковать результат.
- Не перезаписывать существующие final/temporary outputs.
- Публиковать общий progress contract.

## Последствия

Fast mode работает быстро, но зависит от keyframes. Accurate mode требует CPU
и перекодирования. Немедленная отмена активного FFmpeg и детальный progress
откладываются до managed process runner в Job System.
